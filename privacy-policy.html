账本之星 隐私政策

生效日期：2026-09-04
应用名称：账本之星（Ledger Star）　开发者：blithesome
包名：com.blithesome.ledgerstar

一、引言

「账本之星」是一款纯本地的记账工具。开发者不运营任何服务器，应用不包含任何网络请求代码，你的账目数据全程保存在你自己的设备上。

本政策说明应用如何处理（事实上是"不处理"）你的信息。

二、我们收集哪些信息

我们不收集任何个人信息。

  • 不收集姓名、手机号、邮箱、通讯录、位置、设备标识符等任何个人数据
  • 应用内没有任何数据上传逻辑，不具备向服务器发送数据的能力
  • 不需要注册或登录，没有账号体系
  • 不使用任何第三方统计、广告或崩溃上报 SDK

你录入的每一笔账目（金额、分类、备注、日期）都只写入设备本地数据库，开发者无法访问，也无法通过任何途径获取。

三、权限使用说明

应用仅申请以下两项系统权限，均为"使用时授权"。你可以随时在系统设置中关闭，关闭后对应功能不可用，但不影响其他功能。

权限用途是否必需数据处理方式
麦克风（ohos.permission.MICROPHONE） 「语音记账」：识别你说的一句话（如"午饭花了35元"）并转成文字记账 否 仅在您点击麦克风期间采集；识别由系统语音识别能力完成，应用不保存、不上传录音音频；识别结果仅用于填充记账表单
生物认证（ohos.permission.ACCESS_BIOMETRIC） 「应用锁」：开启后可用指纹 / 人脸快速解锁应用 否 生物特征由系统 TEE 安全环境管理，应用仅获取"通过 / 失败"结果，不接触、不存储任何生物特征数据

未开启相关功能时，应用不会申请或使用上述权限。

四、语音与短信记账的处理方式

语音记账：语音识别通过 HarmonyOS 系统提供的语音识别能力完成。当你点击麦克风说话时：

  • 音频仅用于当次识别，识别结束后立即释放
  • 应用不保存录音文件，不上传音频到任何服务器
  • 识别出的文字经本地解析后填入记账表单，由你确认后才会保存

短信记账：应用在本地解析你主动粘贴或分享过来的银行动账短信文本，提取金额、商户、日期等字段。

  • 应用不申请、也不具备读取手机短信的权限（HarmonyOS 中短信读取为系统级受限权限，三方应用无法获取）
  • 短信内容不会离开你的设备，不上传、不留存原始短信

五、数据存储与安全

  • 存储位置：全部数据保存在设备本地数据库中（应用沙箱目录），不上传云端
  • 应用锁密码：只保存 SHA-256("ledger_star:" + 密码) 摘要，不保存明文密码；忘记密码可通过应用内"忘记密码"清除本地数据后重置
  • 生物特征：由系统安全环境（TEE）保管，应用不接触
  • 数据导出：可在「设置 → 数据管理 → 导出备份」将数据导出为 JSON 文件，保存到你自己指定的位置
  • 数据清除：「设置 → 数据管理」提供清空账目、清除全部本地数据等操作，执行后数据不可恢复

请注意：卸载应用会删除全部本地数据，且不同签名版本的安装包之间无法直接继承数据。建议在卸载或换机前先使用「导出备份」。

六、信息共享与披露

我们不向任何第三方共享、出售或披露你的数据——因为开发者从一开始就拿不到你的数据。

七、第三方服务

应用不包含任何第三方 SDK，不集成广告、统计、推送、支付等第三方服务。

八、你的权利

  • 访问与导出：随时在应用内查看全部账目，或导出为 JSON 文件
  • 删除：在应用内一键清空账目或清除全部本地数据；卸载应用即彻底删除
  • 关闭权限：在系统设置中随时关闭麦克风或生物认证权限
  • 关闭应用锁：在「设置 → 安全与隐私」中随时关闭

九、未成年人保护

应用不面向未满 14 周岁儿童定向提供服务，也不收集任何未成年人信息。若未成年人使用，建议在监护人指导下进行。

十、政策更新

如本政策发生变更，我们会在本页面更新内容。若变更涉及数据处理方式的实质调整，会通过应用内提示告知你。
